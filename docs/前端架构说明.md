# CampusTech 前端架构说明

## 路由与代码分割

- 首屏保留轻量页面：`HomePage`、`PostListPage`、`LoginPage` 等直接静态 import。
- 重页面使用 `React.lazy` + `Suspense`：`PostCreatePage`、`PostEditPage`、`PostDetailPage`、`ProfilePage` 按需加载，路由切换时显示 `LoadingSpinner` fallback。
- TipTap 编辑器通过 `LazyPostEditor` 动态 import，仅在发帖/编辑页加载；校验逻辑抽到 `postEditorValidation.ts`，避免页面模块静态依赖编辑器 bundle。

## Bundle 体积对比（子任务 H）

| 指标 | 优化前 | 优化后 |
| --- | --- | --- |
| 最大 JS chunk | ~803 KB（含 TipTap，Vite 报 >500KB 警告） | **286 KB**（`index-*.js` 主 chunk） |
| TipTap 编辑器 chunk | 打入主 bundle | **408 KB** 独立 `PostEditor-*.js`，仅发帖/编辑时加载 |
| 首屏 JS（主 chunk gzip） | — | **89 KB** |

优化手段：路由懒加载 + TipTap 动态 import + 校验函数与编辑器解耦。列表页首屏不再下载 TipTap 相关代码，主 chunk 体积约下降 **64%**。

## 其他轻量优化

- `PostCard` 使用 `React.memo` 减少列表重渲染；封面图 `loading="lazy"`。
- `PostListPage` 设置 `staleTime: 60_000`，60 秒内切换分页/分类时复用缓存，减少重复请求。
