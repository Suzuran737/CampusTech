## 版本 B：标准版（推荐，3–4 条 bullet）

**CampusTech 技术社区** | React 19 · TypeScript · Vite · TanStack Query · TipTap · Vitest  
*个人项目 · 前端负责人 · 2025–2026*

- 集成 TipTap 富文本编辑器，设计「编辑 → DOMPurify 前端过滤 → 后端 sanitize-html 再过滤 → 安全渲染」三层 XSS 防护链路，Vitest 覆盖 script / 外链 img 等过滤用例
- 使用 TanStack Query 管理帖子、资讯、个人帖子等多源分页数据，统一封装 Loading / Empty / Error 状态组件，列表页 debounce 搜索 + `staleTime` 缓存
- 路由懒加载 + TipTap 动态 import，首屏 JS 主 chunk 由 ~803 KB 降至 286 KB（约 -64%）；PostCard `React.memo`、封面图 lazy 等轻量优化
- 实现 JWT 路由守卫、Profile 双 Tab + URL 深链、评论两层回复、FormData 图片上传等完整社区交互流程

## 版本 C：略详细（空间充裕时）

**CampusTech 技术社区** | React 19 · TypeScript · Vite · React Router · TanStack Query · Tailwind · TipTap  
*全栈联调个人项目（前端为主）· 2025–2026*

- **富文本与安全**：基于 TipTap 实现发帖/编辑；前后端白名单过滤（DOMPurify + sanitize-html），img 仅允许 `/uploads/` 路径，展示层再次消毒；配套 Vitest XSS 回归测试
- **数据与体验**：TanStack Query 管理列表/详情/评论等多源请求，设计 `['posts', page, category, keyword]` 等缓存键；debounce 搜索、分页、分类筛选；404 / 空态 / 错误重试统一 UI
- **性能**：`React.lazy` 拆分详情/发帖/个人中心；`LazyPostEditor` 动态加载 TipTap；校验逻辑与编辑器解耦，避免静态 import 打穿 code split
- **工程化**：响应式布局 + 移动端导航；ProtectedRoute / GuestRoute；Axios 封装 REST API；与 NestJS + PostgreSQL 后端联调

**后端（一行带过即可）**：NestJS + Prisma + JWT REST API
